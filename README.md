# Skin Disease Detection Project

## Overview
This project is developed to detect and classify different skin diseases using image processing and machine learning techniques. The system analyzes skin images, extracts important features, and predicts the disease category.

## Objective
- To study skin disease patterns from images  
- To extract meaningful features from skin images  
- To classify skin diseases using machine learning models  

## Methodology
1. Input skin images are collected  
2. Images are preprocessed for better analysis  
3. Feature extraction is performed  
4. Machine learning models are trained  
5. The model predicts the skin disease  

## Feature Extraction Techniques
- Color Moments  
- GLCM (Gray Level Co-occurrence Matrix)  
- LBP (Local Binary Pattern)

## Machine Learning Models
- K-Nearest Neighbors (KNN)  
- Support Vector Machine (SVM)  
- Random Forest  

## Tools and Technologies
- Python  
- OpenCV  
- NumPy  
- Pandas  
- Scikit-learn  
- VS Code / Jupyter Notebook
